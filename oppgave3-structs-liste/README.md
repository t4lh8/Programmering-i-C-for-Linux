# Oppgave 3 - Structs og dynamisk minne

**Mål:** bruke `struct`, `malloc`/`free` og bygge en enkeltlenket liste.

**Oppgave:** lag en handleliste som en lenket liste. Legg til varer, skriv ut
lista og frigjør alt minnet til slutt (ingen minnelekkasjer).

```bash
gcc -Wall -Wextra -o handleliste handleliste.c
./handleliste
```
